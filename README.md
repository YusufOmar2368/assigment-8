This project analyzes and compares multiple text files using Natural Language Processing (NLP) techniques to identify stylistic patterns and similarities between authors. The script processes each input file by tokenizing the text, applying stemming and lemmatization, extracting named entities, and generating trigram frequencies. It then compares documents using TF-IDF cosine similarity and trigram-based Jaccard similarity to determine how closely related the texts are. The goal is to provide both linguistic insight and quantitative similarity metrics across documents.

The implementation is structured using modular functions rather than classes to keep the workflow efficient and readable. Key components include tokenization (tokenize), stemming (stem_tokens), lemmatization (lemmatize), named entity recognition (named_entities), and trigram extraction (trigram_counts). Additional functions such as pairwise_tfidf and pairwise_trigram_jaccard compute similarity scores between documents. Each function operates on processed text and returns structured outputs (lists, counters, or dictionaries), which are aggregated in the main analysis pipeline for reporting. The script uses external libraries including NLTK, spaCy, and scikit-learn to handle linguistic processing and vectorization tasks.

One limitation of this project is its reliance on pre-trained models (e.g., spaCy’s en_core_web_sm), which may not perfectly capture nuanced language differences or domain-specific vocabulary. Additionally, stemming can sometimes reduce words too aggressively, while lemmatization depends on correct part-of-speech tagging. The analysis also assumes clean input text files and may require preprocessing for noisy or irregular data.
